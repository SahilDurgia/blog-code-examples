# Blog code examples

Runnable versions of the snippets from the articles on
[sahildurgia.dev/blog](https://www.sahildurgia.dev/blog).

The posts keep snippets short on purpose — just enough to make the point. The
folders here are the full version: each one runs on its own, prints what it
claims, and includes the variations the article mentions but doesn't have room
to show.

## Running them

Every `index.js` is plain Node with **no dependencies**. Node 18 or newer:

```bash
node javascript-fundamentals/event-loop-order/index.js
```

The React example is a module rather than a script — see its own README.
